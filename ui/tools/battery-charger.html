工具说明

工具名称：充电分析工具
版本号：V1.2.9
作者：TabonTan
充电数据分析：支持 CSV 文件预校验、50% / 80% / 100% 时间、首次 Status = Full 截止判定、截止电流与满电电压、公司时间标准、充电/温度曲线、SOC 分段，以及双文件关键指标对比。

放电数据分析：支持单文件放电时长、容量/能量、平均/峰值电流、电压/温度范围、SOC 区间精细分析，以及双文件关键指标、区间指标与曲线对比；区间新增 min/%、放出容量、mAh/%、ΔV、mV/%、放出能量与相对状态判断，并提供 20% 以下低电量专项分析；放电电流曲线叠加移动平均滤波辅助线；自动忽略电池电压为 0 的异常采样行；最后一档统计到实际关机电量。

充电 IC 寄存器分析：支持 SC89601D、SC89890H、SC89896、SC8549D、UPM6722、UPM6920A；可解析单份 dump，也可对两份 dump 做寄存器级与 bit-field 级差异解析，显示 Hex 变化、XOR、翻转 bit、字段含义与物理量变化。
