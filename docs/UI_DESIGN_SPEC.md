# TabonKB 研发工作台 (Workbench) UI 交互设计规范：极致简约美学

> **规范定位**：本规范是 TabonKB 研发工作台前端组件、弹窗、侧边栏及所有扩展工具（如 OpenGrok、Gerrit、Jira、本地工程等）UI/UX 设计的**第一约束**。
> **核心原则**：工作台是驱动开发工程师高频使用的个人效能终端，“**简约就是美（Minimalist Aesthetics）**”是不可违背的设计铁律。界面应以**操作为中心**，而非解说为中心；拒绝冗余信息，追求极致克制与丝滑交互。

---

## 1. 核心设计哲学 (Core Philosophy)

1. **个人专属高频工具定位**：
   - 使用者为专业开发者，具备完整的业务上下文，**无需在界面中反复教学或放置大段说明**。
   - 界面应当像专业 IDE（如 VS Code、Cursor）或原生系统菜单（如 macOS 状态栏菜单、Raycast）一样干练、精致。
2. **克制与留白 (Restraint & Negative Space)**：
   - 能用一个词表达的，不用一句话；能用图标与微标表达的，不用长文本。
   - 严禁在功能弹出面板、快捷栏中插入长 URL、协议描述、段落级使用教程或大面积占位卡片。
3. **沉浸与无感 (Invisible Utility)**：
   - 选项即选即存（选择后自动持久化写盘），免去多余的“保存/确定/应用”按钮。
   - 点击外部空白自然退出，不依赖显式的“X”关闭按钮。

## 2. 文本与信息密度规范 (Typography & Density)

| 场景 | 规范标准 | 严禁反模式 (Anti-Patterns) |
|---|---|---|
| **面板标题** | 采用 2~4 个字精炼名称（如「选项」），或纯菜单列表无头设计 | 严禁使用「智能体集成与选项配置」等冗长套话 |
| **功能项描述** | 一律简化为 4~6 个字符的短标签（如 `展锐主线`、`MTK 海外版`） | 严禁出现「内网源码检索与切片阅读（http://...）」等段落 |
| **状态呈现** | 采用微标（`tw-opt-badge-tag`，如 `待接入`、`Auto`）配合微动效点 | 严禁在卡片底部增加解释性灰字（如“预留项：后续支持...”） |
| **URL 与路径** | 仅在鼠标悬停的 Tooltip (`title`) 中展示，严禁暴露在正文 UI 中 | 严禁将 `http://192.168.1.12:7080/...` 直接渲染在列表或卡片正文 |

## 3. 弹窗与层叠架构：级联浮窗 (Cascading Popovers)

参考 macOS / Windows 原生级联菜单与 Raycast 设计：

### 3.1 水平层叠与“无缝微重叠”
- **右侧展开优先**：主面板只暴露顶级入口，二级配置以浮窗形式向**右侧级联滑出**。
- **微重叠消除视觉缝隙**：
  - 子浮窗必须向主面板轻微叠合 **`4px ~ 6px` 负边距**（如 `left: calc(100% - 6px)`）；
  - 严禁在父子浮窗之间留下空白裂隙（Gap），利用高层级（`z-index: 220`）叠加产生连贯的质感。
- **边界自适应翻转**：
  - 必须包含视口检测逻辑：当屏幕右侧空间不足（`popoverRect.right + width > window.innerWidth`）时，自动向左侧翻转（`right: calc(100% - 6px); left: auto;`），防止被截断。

### 3.2 垂直基线对齐与任务栏避让
- **底端对齐向上生长**：
  - 由于输入工具栏通常位于窗口底部，子浮窗的垂直定位**必须与主框底端对齐**（`bottom: 0px; top: auto;`），向上部开阔区域伸展；
  - 严禁从 `top: 0` 向下盲目展开，彻底杜绝浮窗探出 Obsidian 窗口下边缘而被系统任务栏截断（造成“浮窗不完整、割裂感”）。
- **最大高度限制**：
  - 子列表设置自适应最大高度：`max-height: min(300px, calc(100vh - 120px))`，并配置平滑滚动条。

## 4. 交互微动效与闭环 (Interaction & Feedback)

1. **双重唤出机制**：
   - 鼠标点击（Click）与鼠标移入（Hover / `mouseenter`）均可即时展开级联子菜单；
   - 鼠标移至同级其他菜单项时，自动平滑收起当前子菜单。
2. **即选即存即关**：
   - 点击选项立即持久化保存（写入 `localStorage` 或插件数据），通过 Obsidian Notice 轻提示（1.8s），并立即优雅收起弹窗。
3. **全局空白自然退出**：
   - 监听全局 `click` 事件，点击外部任意空白区域无感退出选项面板，无需额外点击关闭图标。

## 5. 视觉令牌与材质 (Design Tokens & Material)

```css
/* 1. 高级毛玻璃背景材质 */
backdrop-filter: blur(20px) saturate(190%);
-webkit-backdrop-filter: blur(20px) saturate(190%);

/* 浅色主题底色与微光边框 */
background: rgba(255, 255, 255, 0.92);
border: 1px solid rgba(226, 232, 240, 0.85);
box-shadow: 0 12px 32px -4px rgba(0, 0, 0, 0.18), 0 4px 12px -2px rgba(0, 0, 0, 0.08);

/* 深色主题底色与边框 */
.theme-dark {
  background: rgba(30, 41, 59, 0.94);
  border-color: rgba(51, 65, 85, 0.85);
  box-shadow: 0 16px 36px -4px rgba(0, 0, 0, 0.55);
}

/* 2. 紧凑菜单项排版 */
padding: 7px 9px;
border-radius: 6px;
font-size: 12px;
font-weight: 500;

/* 3. 图标规范 */
IconPark 线性图标，尺寸严格限制在 12px ~ 14px，避免巨大彩色图标打乱排版呼吸感。
```
